凭据池 来自本机 OfficeAce 客户端

凭据来源说明

凭据由本服务从本机文件中自动读取，只读不写，不会影响 OfficeAce 客户端本身：
~/.office-claw/.jiuwenclaw/config/routing_state/users/<账号ID>/models.json
默认每 45 秒重新扫描一次；OfficeAce 刷新凭据后本服务会自动跟进。 扫描到 0 条时：点本页右上角「换个账号登录」自己登一个（不需要 OfficeAce 桌面端）；
如果你已经装了 OfficeAce，也可以登录它并发一条消息，再点「重新发现凭据」。

账号池 本机发现 + 手工导入的账号，及其凭据

积分额度（还剩多少）

手工导入账号

适合从别的机器搬账号：把目标机器 models.json 里的 api_base 与 custom_headers.Authorization 填进来即可。导入的账号只存元数据，不动 OfficeAce 任何文件。

账号列表

账号数据来源

一个账号在磁盘上散落在三处，本服务把它们拼成一条记录（只读不写）：
① 上游地址与鉴权：~/.office-claw/.jiuwenclaw/config/routing_state/users/<账号ID>/models.json
② 临时 AK/SK 与过期时间：<安装目录>\packages\api\.config\secure-config-nodejs\oauth-<账号ID>.json
③ 模型目录：~/.office-claw/users/<账号ID>/model.json
② 用 Windows DPAPI（当前用户）解开安装密钥，再用 AES-256-GCM 解密档案，因此能显示准确的剩余时长。
账号 ID 形如 <华为云账号ID>:<IAM用户ID>，就是 OfficeAce 自己的目录名。

积分构成 每个号还剩多少积分

总览

每日签到

「每日签到有礼」「登录翻倍礼」这类活动每天 23:59:59 到期，当天不领就作废。 每天 09:05 会自动领一次（可在 config.json 的 credits.autoClaim 改时间或关掉）。领取走的是 POST /v1/subscription/bonus/claim，同一天同一个活动只会生效一次。

每个账号

近 30 天消耗（积分/天）

数字来自华为 AgentArts 的 /v1/subscription/usage?sku_attr_code=officeace_points， 按北京时间的自然日分桶。积分单位是 officeace_points，扣费顺序是 先到期早的先用（先奖励、后套餐）。

模型积分费率

「多少 token 扣 1 积分」来自 /v1/model-token-rates。缓存命中（cached）最便宜， 同一积分能换的 token 最多，约是输入价的 4 倍。

额度是怎么查出来的

直接问华为云，本机 OfficeAce 登录与否不影响（只要临时 AK/SK 没过期）：
① GET /v1/claw/client-permission-validate —— 校验凭据，取该账号的专属网关地址
② GET {网关}/v1/subscription —— 套餐 + 积分： skus[].quotas[] 里 sku_attr_code=officeace_points 的 sku_value（总额）减 current_value（已用）就是剩余； bonus_skus[] 是奖励积分，算法一样
③ GET /v1/subscription/usage —— 每天花了多少积分、多少 token
认证用华为 V11-HMAC-SHA256 签名（作用域 <日期>/cn-southwest-2/apic， 签名密钥由 AK/SK 派生），全程只读，不会消耗任何额度。

授权 / 注册

本机 OfficeAce 服务

一键授权走的是本机 OfficeAce 自己的登录链路（/api/login/authorize → 华为云登录页 → /api/login/oauth/poll）， 因为 PKCE 的 code_verifier 在应用进程里，只有这样应用才能把授权换成的临时 AK/SK 落到磁盘。 授权完成后本服务自动把新账号并入号池，勾选「入池后用别名」可顺手改个名。

授权任务

自动轮询（每 3 秒，最长 10 分钟）

批量注册 / 开通

邀请码兑换

兑换走本机 OfficeAce 的 /api/login/invitation。 常见失败原因：邀请码无效 / 今日额度用完 / 账号未实名认证 / 账号欠费 / 权限不足。

注册链路的真实边界

华为云注册页必须过「图形验证码 + 短信验证码」，图形验证码由服务端下发、一次性，没有稳定可复用的自动化通道， 所以本模块把注册做成「队列 + 状态机 + 可插拔接码」，能自动的全自动，剩下的人工只做两步： 填一次图形验证码、点一次提交。

自动的部分：生成带手机号的注册链接 → 取短信码（手工 / 接码平台）→ 检测新账号生效 → 触发一键授权 → 用别名并入号池 → 兑换邀请码开通额度。
手工的部分：填图形验证码、点提交（在浏览器里）。

注册入口：https://reg.huaweicloud.com/registerui/register.html
